## Почему v3 (v2 провалился на реальных страницах)

- **SSO**: scripted fetch мёртв — скачивание всегда руками, фолбэк с выдуманным
  URL только путал.
- **NER провалился системно**: en-модель на кириллическом тексте
  галлюцинирует («Грейд», «Сценарии» → PERSON, мусорные мультитокен-спаны),
  латинские ФИО в кириллическом окружении теряет («Aleksandra» без фамилии).
  Score ложных и истинных одинаковый (0.85) — порогом не отделить.
  Итог прогона на реальных доках: ~26 ложных вырезаний, 2 пропуска ФИО.
- **Решение**: ПДн — руками человека по списку подозрений (fail-visible),
  секреты — автоматика gitleaks + regex (fail-closed). Именно те части, где
  автомат надёжен, остаются автоматическими.

## Стек

Node + **mammoth** (docx→HTML, npm, локально в скилле) + **domino/turndown**
(HTML→md; `fixTables`: первая строка → th, без `<p>`/`<br>` в ячейках — без
этого gfm-плагин оставляет таблицы сырым HTML) + **gitleaks** (scoop).
Без python/venv/NER — venv на ~1.1 ГБ удалён.

## Команды

- `to-md <in.doc|in.docx|in.html> [--out f.md]` — конвертация; md рядом с
  исходником. Сразу гоняет mdcheck по выводу: отчёт в JSON, exit-код = код
  mdcheck (0/1/3; 2 — ошибка конвертации).
- `mdcheck <f.md>` — exit `0` чисто / `1` секреты (стоп) / `2` ошибка /
  `3` только подозрения (явно снять с пользователя).
- `stats <f.md>` — счётчики структуры (строки, таблицы, дубли-блоки,
  CSS-остатки); контент не печатает — безопасен на негейтованном выводе.

## Правила (см. SKILL.md)

- Агент читает только md после mdcheck (0, или 3 снят пользователем) —
  «читает» = любым способом: read, cat, grep, node.
- Вывод `to-md` — сырой до exit 0; повторный конверт сбрасывает гейт.
  Структуру негейтованного вывода смотрит только `stats`.
- exit 1 не «уговаривается» — только правка файла.
- Подозрения печатаются замаскированными; сырье в чат не тащится.
